# USER.md - 사용자 모델

다음 세션에도 이어질 사용자 선호와 확인된 사실을 지시문으로 적는다.

- 지시문 하나에 한 줄. `항상`, `절대`, `가능하면`처럼 지시형으로 시작한다.
- 각 지시문 앞에 `<!-- observed: YYYY-MM-DD | status: active -->`를 붙인다.
- 선호가 바뀌면 이전 항목을 `superseded`로 바꾸고, 활성 지시문을 그 자리에서 다시 쓴다. 서로 모순되는 활성 지시문을 남기지 않는다.
- 사용자 프로필이 아닌 오래 남을 사실과 결정은 `MEMORY.md`에 적는다.
