# 0004. 패치가 빠지면 휴대폰으로 알리기만 하고 자동으로 다시 입히지 않는다

## 맥락

OcuClaw 업데이트는 플러그인 폴더를 통째로 바꿔 우리 훅을 지운다. 업데이트를 막으려면 OcuClaw 버전을 고정해야 하고, 그대로 두면 Hey Even이 조용히 다시 잘린다. 새 버전에서는 기준 문자열이 달라져 패치가 들어가지 않을 수도 있고, 버그가 정식으로 고쳐졌을 수도 있다.

## 결정

OcuClaw 버전을 고정하지 않는다. LaunchAgent 감시자가 Gateway 시작마다 지점별 검사를 돌리고, 빠졌으면 페어링된 휴대폰 OpenClaw 앱으로 빠진 지점과 재적용 명령을 한국어로 알린다(30초 간격 최대 10분 재시도, 실패 시 로컬 로그). 재적용은 사람이 명령으로 한다.

## 대안

- **OcuClaw 버전 고정**(권장안으로 제시됨): 패치가 사라질 일은 없지만 보안·기능 업데이트를 놓친다. 사용자가 거절했다.
- **감시자가 자동 재적용 + 재시작**: 새 버전에 맞지 않는 훅을 기계적으로 넣거나, 이미 고쳐진 버그 위에 중복 수정을 얹을 수 있다. Gateway 재시작이 사용자 모르게 일어나 휴대폰 연결이 끊긴다. 패치는 사람이 새 버전을 보고 판단해야 하는 일이다.
- **OpenClaw 훅·자동화로 검사**: Gateway 안에서 돌면 Gateway가 OcuClaw 로드에 실패한 경우를 볼 수 없다. Gateway 밖 LaunchAgent가 로그를 보는 쪽을 택했다.

## 결과

- 업데이트부터 재적용까지 Hey Even은 첫 조각만 보낸다. 이 창은 사람이 알림을 보고 움직이는 시간만큼이다.
- 휴대폰이 연결되지 않은 상태가 10분 넘게 이어지면 알림은 로그에만 남는다.
- 감시자는 Gateway 로그 문구(`[gateway] ready`)와 검사 명령 출력 형식에 의존한다. 둘 중 하나가 바뀌면 감지가 조용히 멈춘다.
- 검사 자체가 실패하면 알리지 않는다(거짓 경보보다 놓침을 택했다).
